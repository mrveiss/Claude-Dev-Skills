When to use: answering a question from memory, or finding who wrote what or when.

# Lookup

1. Find the shelf: `library/catalog/by-topic.md` (or the library README if the project keeps one).
2. Read the shelf `CARD.md` (a table of chapters, purposes and counts, so you pick without reading entries).
3. Open ONE chapter; open a second only if the first names it. Follow the entry link to the fact only when the one-line hook is not enough.
4. On a conflict the owner book outranks other books; within a book the newer dated entry wins.

| Question | Catalogue (index, then one group file) |
|---|---|
| What do we know about topic X | `catalog/by-topic.md` |
| What did author A write | `catalog/by-author.md` |
| What changed around a date | `catalog/by-date.md` (one file per month) |
| Which entry is titled ... | `catalog/by-title.md` (one file per letter) |
| All feedback, gotchas, projects | `catalog/by-kind.md` |
| What do we know about issue or PR #N | `catalog/by-issue.md` (grouped per thousand) |

- Every catalogue line starts with its call number `ROOM.SHELF/author/CHAPTER/date`; see `classification.md`.
- A date shown `~2026-09-03` came from a file time and is approximate; `unknown` means a bulk-copy file day (threshold in `classification.md`), so treat it as undated.
- A catalogue that looks stale: run `shelving.md` step 3, never edit it by hand.
